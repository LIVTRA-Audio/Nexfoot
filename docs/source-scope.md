# Source and licenses

This repository contains the Nexfoot firmware, SDK integration files,
the NanoBridge protocol, and the shared DAW SDK.
It also includes the community build and update tools and
[recovery boot references](../recovery/README.md).

The Ableton Live and FL Studio integrations are separate projects that use
the shared DAW SDK.

Project code and documentation are licensed under [Apache-2.0](../LICENSE).
Modified upstream files retain their original notices. The build tools fetch
the JieLi SDK revision listed in [the dependency lockfile](../dependencies.lock.json).
Dependencies retain their upstream license terms. See [NOTICE](../NOTICE)
for attribution.
